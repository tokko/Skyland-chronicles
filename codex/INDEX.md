# Codex Index

The live catalogue of every entity tracked by the codex. Read this file every turn — it tells the orchestrator and subagents what exists, what state it is in, and where to look up details.

This file is updated at the same time as any scene commit that adds or alters an entity.

## How to read

Each entry: `[type] slug — short tag — status — file path`.

- **type**: character | location | faction | magic | event | artifact
- **slug**: lowercase-hyphenated identifier used in cross-references
- **short tag**: one-line description so the orchestrator can decide whether the entity is relevant without opening the file
- **status**: alive/dead, intact/destroyed, active/dormant, known/hidden, etc.
- **file path**: where the full entry lives

## Open continuity questions

- **Varl's escape mechanism from the Groundlands** (book 2). Mathias Varl is presumed dead aboard the Prowler at book-2 ch.26, but his ultimate fate has never been on-page confirmed. If he survived, the route is unknown.
- **Varl's ultimate fate post-book-3.** Not referenced in source-book-3. Presumed dead by Marissa and Kendall; no on-page confirmation either way.
- **Wylah's confirmed status** (book 2). Separated from the main group at book-2 ch.22 in the cave system; not heard from again. Presumed dead but not confirmed.
- **Malkareth's potential resurrection.** Book-1 ch.39 establishes the soul-containment rule that would, in principle, permit a dragon's soul to be recovered if a vessel were prepared in time. Malkareth's soul was not deliberately captured before his body atomised at the Great Geyser (book-1 ch.51). If any fragment was carried in Kyra's gem and later in Epitome, the source does not say so. Flag for the rewrite to decide whether to leave silent or use.
- **Zandor's final whereabouts** after source-book-3 ch.15. He escapes Marissa at the Ca'el capital; the source does not place him on-page again. Presumed alive and at large in the Ca'el remnant; surfaces only by implication (Ca'el remnant operations) in subsequent chapters.
