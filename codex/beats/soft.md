# Soft Beats

The default scaffold. Soft beats are the orchestrator's working plan for pacing and texture between the hard beats. They may be:

- dropped (if the story takes a better path),
- replaced (with a different beat that does the same narrative work),
- reordered,
- invented (new soft beats added when pacing requires).

Soft beats may be promoted to hard, but only with explicit user approval.

**Status: empty until manuscript is ingested.**

## Format

Each beat:

```
### <BEAT-ID> — <Short title>
- **Book / planned location**: book-N / chapter MM area
- **Function**: pacing / character work / setup / payoff / breather / etc.
- **Description**: what happens
- **Status**: pending | landed (scene: ...) | dropped (reason) | replaced by <BEAT-ID>
```
