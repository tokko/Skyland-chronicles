# A/B Mapping — Scene-02 Draft Pass 1

This file records which model produced which blind-labelled draft. **The reviewer does not read this file.** The reviewer scores `draft-1-A.md` and `draft-1-B.md` against the same criteria, then picks a winner; the orchestrator opens this file only after the verdict is in.

| Label | Model | Agent invoked |
| ----- | ----- | ------------- |
| **A** | Sonnet 4.6 (current generation) | `scene-writer` (model: sonnet, frontmatter default) |
| **B** | Sonnet 3.7 (`claude-3-7-sonnet-20250219`) | `scene-writer-3-7` (model pinned in frontmatter) |

**Note**: the original A/B target was Sonnet 3.5 (`claude-3-5-sonnet-20241022`), but the harness has no access to that family. Per user direction, the test was re-pointed to Sonnet 3.7 — the next-older Sonnet generation reachable from this environment. This changes the hypothesis being tested: instead of "did the 3.5-era prose voice carry an edge the later Sonnets lost", the test now asks "does the older-but-not-ancient 3.7 produce better prose than the current 4.6 for this voice." The result is informative either way but the original 3.5-prose framing is parked for now.

## Test parameters

- **Brief**: `books/book-1/chapter-01/scene-02.brief.md` (shared, identical inputs).
- **Output paths**: `draft-1-A.md` and `draft-1-B.md` in this directory.
- **Reviewer**: Opus 4.7 reads both blind, scores both against the same criteria, picks a winner. The losing draft is archived; the winner becomes `draft-1.md` and continues through the standard pipeline.
- **Lock-in**: after scene-02 the winning model is locked as the scene-writer default for all subsequent scenes (per CLAUDE.md Pipeline parameters, "Pending model A/B test").
- **One-shot**: the A/B runs once, on scene-02 only. Not repeated.

## Why blind

To remove the orchestrator's and reviewer's prior beliefs about model identity from the scoring. The reviewer reads two pieces of prose, scores them on the same criteria, picks one. The orchestrator opens this file only after the verdict, applies the lock-in, and notes the decision in `STATUS.md`.
